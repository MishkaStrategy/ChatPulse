# Приватность ChatPulse

ChatPulse — локальное расширение Google Chrome.

## Какие данные хранятся

В `chrome.storage.local` сохраняются:

- список добавленных URL чатов;
- пользовательские названия чатов;
- выбранный интервал;
- текст команды и стоп-фразы;
- выбранная тема;
- локальный журнал состояния;
- технические отпечатки последних ответов, необходимые для защиты от повторной отправки;
- если пользователь сам включает Telegram: Telegram chat ID и bot token в отдельной локальной конфигурации.

Bot token считается секретом. Он не возвращается в публичный runtime-state ChatPulse и после сохранения не показывается обратно в интерфейсе.

## Что не собирается

ChatPulse не собирает и не передаёт разработчику:

- cookies;
- пароли, email, коды входа или passkey;
- историю браузера;
- содержимое переписки как отдельную базу данных;
- аналитику, телеметрию или рекламные идентификаторы;
- Telegram bot token или chat ID на сервер разработчика — собственного сервера у ChatPulse нет.

## Сеть

Основная автоматика выполняется локально в Chrome и взаимодействует только со страницами ChatGPT, которые пользователь открыл или добавил сам.

Telegram полностью опционален. При включении Chrome отдельно запрашивает доступ только к `https://api.telegram.org/*`. ChatPulse отправляет напрямую в Telegram Bot API:

- название отслеживаемого чата, ограниченное по длине;
- факт и результат автоматической отправки команды продолжения;
- тестовую строку только по кнопке **Отправить тест**.

В Telegram не отправляются текст ответа ChatGPT, URL разговора, стоп-фраза или содержимое поля команды. Ошибка Telegram не вызывает повторную отправку команды ChatGPT.

Опциональный Telegram permission можно отозвать в Chrome. Это не мешает сохранять и использовать обычные настройки ChatPulse; уведомления просто перестанут отправляться, пока доступ не будет выдан снова.

## Удаление данных

Удалите расширение в `chrome://extensions`, затем при необходимости очистите его данные через настройки Chrome. Удаление расширения удаляет его локальное хранилище, включая сохранённый Telegram bot token.

## Ограничение ответственности

DOM и интерфейс ChatGPT, а также Telegram Bot API могут изменяться без уведомления. Перед использованием в важных сценариях проверяйте журнал и работу расширения на тестовом чате.
