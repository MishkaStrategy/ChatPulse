## Что делает ChatPulse

ChatPulse работает внутри уже авторизованного профиля Chrome и следит только за выбранными страницами `chatgpt.com`. Когда завершённый ответ ассистента остаётся неизменным нужный интервал, расширение может безопасно отправить команду продолжения. Базовая команда:

```text
продолжай и не останавливайся до технического лимита
```

В 0.6.0 каждый чат может иметь собственный профиль, лимиты и режим задачи «до завершения».

## Возможности

- несколько сохранённых чатов с независимым состоянием;
- общий профиль по умолчанию и индивидуальные профили для каждого чата;
- per-chat команда продолжения, интервал, стоп-фраза, лимит продолжений, лимит времени и Telegram policy;
- **Control Center** со статусом, прогрессом, причиной остановки, следующей проверкой и локальной ошибкой каждого чата;
- режим **«Запустить до завершения»** с обязательным guard: стоп-фраза, максимум продолжений или максимум времени;
- точный лимит продолжений: `N` означает максимум `N` отправок, без `N+1`;
- интервалы от 30 секунд до 24 часов;
- безопасная первая проверка без отправки и freshness-preflight непосредственно перед отправкой;
- стоп-фраза по последнему завершённому ответу ассистента, отключающая только совпавший чат;
- защита `at-most-once` от повторной отправки одному ответу;
- `controlRevision`, отменяющий старую in-flight проверку после ручного изменения чата/профиля;
- автоматическое восстановление discarded, frozen и неотвечающих вкладок;
- защита активной вкладки, текущей генерации и пользовательского черновика;
- опциональные Telegram-события после продолжения, при старте задачи, остановке по guard и при общей ошибке автоматики;
- безопасный экспорт/импорт портативной конфигурации JSON без секретов и runtime history;
- локальный журнал событий;
- скины **macOS** и **ChatPulse Preview**;
- версия интерфейса автоматически берётся из Manifest.

## Control Center и профили чатов

Откройте полный интерфейс ChatPulse. В карточке каждого чата отображаются:

- включён ли чат и выполняется ли task mode;
- количество выполненных продолжений и лимит, если он задан;
- прошедшее/максимальное время задачи;
- последняя причина/ошибка и следующая допустимая проверка;
- раскрываемый профиль этого чата.

Поля команды и интервала по умолчанию **наследуются** из общих настроек. Для стоп-фразы доступны три режима: использовать общую, задать собственную или явно отключить её для этого чата. Изменение профиля повышает `controlRevision`: уже запущенная проверка не сможет отправить команду со старыми настройками.

## Режим «до завершения»

Перед запуском задайте хотя бы один guard:

- стоп-фразу;
- `Максимум продолжений`;
- `Максимум времени`.

Без guard ChatPulse не запускает автономную задачу. При запуске только выбранный чат получает новый безопасный baseline и новый счётчик. Если обычное наблюдение было остановлено, ChatPulse включает `taskOnly` engine: проверяется только выбранная активная задача, а остальные обычные чаты не просыпаются. Если обычное наблюдение уже работало, оно продолжает работать как раньше.

Верхняя кнопка **Остановить / Остановить всё** — master-stop. Она отключает фоновый engine целиком и завершает активные task-mode запуски с причиной `global-stop`. Ручной Stop задачи или общий master-stop повышают `controlRevision`, поэтому старая in-flight проверка не может воскресить завершённую задачу или отправить по устаревшему состоянию.

При достижении stop/limit ChatPulse отключает только этот чат и фиксирует точную причину в Control Center. Счётчик увеличивается только после того, как `recordDispatch()` уже зафиксировал результат отправки для `at-most-once`, причём dispatch checkpoint сохраняется локально до Telegram/network уведомления. Поэтому лимит `10` не может привести к одиннадцатой команде.

## Стоп-фраза

ChatPulse проверяет только последний завершённый ответ ассистента. Unicode нормализуется в NFKC, регистр не учитывается, переносы строк и повторяющиеся пробелы схлопываются. Пользовательские сообщения и незавершённая генерация не учитываются.

Если нормализованный ответ содержит эффективную стоп-фразу, расширение отключает только этот чат и ничего ему не отправляет. Значение стоп-фразы и текст ответа не записываются в журнал и не отправляются в Telegram.

## Telegram-уведомления

Telegram выключен по умолчанию. Укажите `Chat ID` и bot token от BotFather, включите **Уведомлять** и сохраните настройки. Chrome отдельно запросит доступ только к `https://api.telegram.org/*`.

Telegram может получить:

- название отслеживаемого чата;
- результат автоматического продолжения;
- факт запуска task mode;
- факт остановки по стоп-фразе, лимиту продолжений или времени;
- общий факт ошибки автоматики без runtime details;
- тестовую строку по кнопке **Отправить тест**.

Для отдельного чата Telegram-события можно отключить в профиле. Текст ответа ChatGPT, URL разговора, стоп-фраза, команда и bot token в Telegram не отправляются. Bot token хранится отдельно в `chrome.storage.local`, не возвращается в публичный runtime-state и не показывается после сохранения.

Ошибка Telegram не влияет на основную автоматику и не может повторить команду ChatGPT.

## Экспорт / импорт

Кнопка **Экспортировать JSON** сохраняет только переносимую конфигурацию:

- общие значения по умолчанию;
- URL/названия отслеживаемых чатов;
- enabled-флаг и per-chat профили.

В JSON **не входят** Telegram bot token, tab/session IDs, fingerprints, `at-most-once` history, логи, ошибки, счётчики и runtime текущих задач.

Импорт заменяет список чатов и общие настройки, но оставляет локальные Telegram credentials нетронутыми. После импорта глобальный мониторинг остаётся остановленным, а chat IDs, runtime identity и baseline создаются заново, чтобы старый файл не мог повторить прошлую отправку.

## Установка

1. Скачайте репозиторий или beta ZIP из GitHub Actions.
2. Распакуйте архив и сохраните папку в постоянном месте.
3. Откройте `chrome://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку `chrome-extension`, внутри которой находится `manifest.json`.
7. Закрепите ChatPulse через меню расширений Chrome.

## Первый запуск

1. Войдите в ChatGPT в том же профиле Chrome.
2. Откройте конкретный чат вида `https://chatgpt.com/c/...`.
3. Нажмите значок ChatPulse или откройте полный Control Center.
4. Выберите **Добавить последний чат ChatGPT**.
5. При необходимости настройте профиль и guard.
6. Запустите обычное наблюдение или **Запустить до завершения**.

Первая проверка новой сессии/задачи только фиксирует текущий ответ. Следующая стабильная проверка может отправить команду ровно один раз.

## Восстановление вкладок

Для управляемых вкладок ChatPulse пытается установить `autoDiscardable: false`. Перед чтением DOM расширение проверяет `discarded`, `frozen`, доступность content script и наличие ошибки страницы. При необходимости вкладка безопасно обновляется, затем ChatPulse ждёт загрузку и гидратацию интерфейса ChatGPT.

Неактивные вкладки без черновика и без нормальной текущей генерации могут периодически обновляться. Активную вкладку и заполненное поле ввода ChatPulse автоматически не перезагружает.

## Приватность и разрешения

Все продуктовые настройки и runtime state хранятся локально в `chrome.storage.local`. У ChatPulse нет backend, телеметрии, рекламы, внешнего ИИ или платных API.

Постоянные разрешения:

- `alarms` — плановые проверки;
- `storage` — локальные настройки/state/журнал;
- `tabs` — поиск, открытие и восстановление сохранённых чатов;
- `scripting` — восстановление content script после обновления вкладки.

Постоянный host-доступ ограничен `chatgpt.com` и `chat.openai.com`. `api.telegram.org` находится только в `optional_host_permissions`. Расширение не запрашивает `cookies`, `history`, `webRequest`, `debugger`, `nativeMessaging` или `<all_urls>`.

Подробнее: [PRIVACY.md](PRIVACY.md) и [SECURITY.md](SECURITY.md).

## Проверка разработки

Требуется Node.js 20 или новее:

```bash
npm run audit:extension
npm run package:beta
```

`audit:extension` проверяет синтаксис, старые stop/controlRevision/recovery/at-most-once гарантии, schema-v4 migration, per-chat profiles, limits/task guards, portable-config isolation, Telegram privacy/permission boundary, сервис-воркер и Manifest V3. GitHub Actions повторяет полный аудит в пяти независимых циклах.

`package:beta` создаёт воспроизводимый `ChatPulse-Chrome-v0.6.0-beta.zip`, его SHA-256 и `ChatPulse-Chrome-v0.6.0-source-manifest.txt` с отдельным SHA-256.

## Статус

Текущая разрабатываемая версия — **0.6.0 beta**. Она расширяет выпущенный 0.5.5 Control Center/task-профилями, лимитами, Telegram operational events и переносимой конфигурацией, сохраняя прежние safety boundaries.

`main` остаётся Chrome-extension-only; отдельное macOS/WebKit-приложение не используется.
