Перенос

Экспорт / импорт конфигурации

Экспорт содержит только общие настройки, список чатов и их профили. Bot token, вкладки, fingerprints, журнал, task runtime и история отправок исключены. Импорт останавливает глобальный мониторинг и создаёт новые безопасные baseline.

Режим задачи

Работать до завершения

  1. 1

    Откройте профиль нужного чата в Control Center.

  2. 2

    Задайте хотя бы один guard: стоп-фразу, максимум продолжений или максимум времени.

  3. 3

    Нажмите «Запустить до завершения». Счётчик и безопасный baseline начнутся заново только для этого чата.

  4. 4

    При выполнении guard ChatPulse отключит только этот чат и запишет точную причину.

Per-chat профили не создают отдельный scheduler: они используют тот же локальный state, `controlRevision`, freshness-preflight и `at-most-once`. Telegram остаётся только опциональным доступом к api.telegram.org.
